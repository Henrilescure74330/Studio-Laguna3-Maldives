Ouverture de l'application… Connectez-vous à claude.ai avec votre compte si on vous le demande.

Sur téléphone, le lien direct ouvre l'appli Claude, qui ne sait pas afficher la gestion. Ouvrez-la dans le navigateur :

  1. Touchez « Copier l'adresse ».
  2. Ouvrez un nouvel onglet dans Safari ou Chrome, collez l'adresse dans la barre du haut et validez.
  3. Si claude.ai vous le demande, connectez-vous avec votre adresse e-mail et le code reçu par e-mail (tapez le code, ne touchez pas le lien du mail).
  4. Ensuite, dans Chrome, menu ⋮ puis « Ajouter à l'écran d'accueil » (sur iPhone : « Partager » puis « Sur l'écran d'accueil »).
  5. Sur Android, si l'appli Claude s'ouvre quand même : Paramètres › Applications › Claude › « Ouvrir par défaut », désactivez « Ouvrir les liens compatibles », puis recommencez.
